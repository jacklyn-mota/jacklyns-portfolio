My Projects

These projects reflect my growing experience in web development, interaction design, and creating user-focused digital experiences.

01 — Sweet Crumbs Bakery

HTML · CSS · Responsive Layout

Sweet Crumbs Bakery gave me the opportunity to explore visual design and problem-solving through a bakery website. I especially enjoyed refining the visual style and organizing the cake selections into cards. This project helped me practice using layout techniques to present information clearly while maintaining a consistent design. I also worked through responsive design challenges with guidance from my peers and instructors, learning how to adapt a website for different screen sizes.

View the Sweet Crumbs Bakery project on GitHub Pages.

02 — Clean Water Caravan

HTML · CSS · JavaScript · Game Interaction

Clean Water Caravan challenged me to connect JavaScript functionality with an engaging game experience. I worked with scoring, a timer, difficulty settings, and interactive feedback to make gameplay more responsive. I also considered how the experience would feel for both experienced gamers and first-time players. Through this project, I learned more about how testing, iteration, and clear feedback contribute to a more intuitive interactive experience.

View the Clean Water Caravan project on GitHub Pages.

03 — Intel Sustainability Summit Check-In

HTML · CSS · JavaScript · localStorage

The Intel Sustainability Summit Check-In project introduced me to using JavaScript and localStorage to retain attendee information in the browser. I developed a check-in interface that records attendee names and team selections, updates attendance totals, and displays the attendee list. This project helped me understand how interactive web features can support practical event workflows and how browser storage can preserve simple data between visits.

View the Intel Sustainability Summit Check-In project on GitHub Pages.
